# Atharv | Personal Portfolio

A responsive, single-page personal portfolio website with a light/dark theme toggle. It introduces me, lists my skills and shows my projects with links to their source code.

**Live site:** https://AtharvS-dev.github.io

## What it does

- Presents an About section, a Skills list and a Projects section with "Source" links to each project's GitHub repository
- Light and dark themes with a toggle button. The choice is saved in the browser (`localStorage`), and the first visit follows the device's theme setting
- Layout adapts to mobile and desktop screens
- Frontend only, with no backend

## Tech stack

- HTML5
- CSS3 (custom properties for theming, Grid and Flexbox for layout)
- Vanilla JavaScript (theme toggle)
- Google Fonts (IBM Plex Sans, JetBrains Mono)
- Hosted on GitHub Pages

## Project structure

```
index.html   page content
style.css    styling and light/dark theme colours
script.js    theme toggle logic
```

## How to run

No build step or installation is needed.

1. Clone the repository: `git clone https://github.com/AtharvS-dev/AtharvS-dev.github.io.git`
2. Open `index.html` in any browser

Or just visit the live site above.
